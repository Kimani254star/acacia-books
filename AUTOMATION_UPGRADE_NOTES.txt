ACACIA BOOKS - AUTOMATION UPGRADE

The Workflow Rules engine has been expanded to monitor supported Acacia Books data collections across the application.

Capabilities:
- Company-scoped workflow rules, execution history, tasks, reminders, notifications and review items.
- Triggers for record creation, update and deletion across supported Sales, Purchases, Inventory, Banking, Expenses, Payroll, Accounting, Projects, HR and related data collections.
- Conditions using all/any matching and the existing comparison operators.
- Actions to create follow-up tasks, reminders, in-app notifications, review queue items, and update the status of the triggering record.
- A status update action writes only the status and updatedAt fields on the triggering record. It is unavailable for deleted records and requires an explicitly entered status.
- Storage watcher handles localStorage.setItem and localStorage.removeItem array changes. Custom screens can raise events with window.acxWorkflowEmit(moduleKey, 'created'|'updated'|'deleted', record, oldRecord, storageKey, recordIndex).
- Workflow tests remain dry-run previews and do not change business records.

Important implementation note:
The app currently uses browser localStorage in several modules. This engine detects supported array-based localStorage collections. Modules using a remote API, IndexedDB, non-array storage structures, or a different browser storage mechanism must call acxWorkflowEmit from their successful save/update/delete handlers to participate reliably. Cross-device/server-side execution requires a backend event processor and is not created by this front-end-only change.
