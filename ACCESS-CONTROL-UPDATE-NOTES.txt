Acacia Books User Management access-list update

Included:
- Added a broad master module/submodule list to User Management's existing module-access checkbox area.
- Added connected-app access checkboxes for Acacia Budget, CRM, Expenses, Inventory, Meet, Payroll, Plans, POS, Sell, and Stock.
- Mail is documented as available to authenticated Books users without a paid-app toggle.
- Added missing master entries to the runtime module/group arrays when those arrays exist.
- Existing User Management save logic persists selected checkbox values into the user's modules array.

Important:
This is a UI/access-assignment inventory update only. It does NOT establish Supabase backend enforcement or sync the connected-app checkbox assignments to app_permissions/user_app_access automatically. The Supabase schema/functions must be wired into authenticated operations in each app, and module/submodule/action IDs must be reconciled with the live navigation before production security claims.
